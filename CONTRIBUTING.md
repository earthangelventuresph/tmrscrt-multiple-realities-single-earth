Thank you for wanting to contribute. This project is open for examination, challenge, and replication — not for silent edits.

## Core Rule
**v1.0 is frozen.**
Do not edit v1.0 directly. If you find an error or want to propose a change, open a GitHub Issue first. Approved changes go into v1.1, v1.2, etc., with a CHANGELOG entry.

## How To Contribute
### 1. Report a Correction
Found wrong equation, typo, wrong citation, wrong figure label?
- Open Issue > Label: `correction`
- Include: File name, line / page, what is wrong, what it should be, source if applicable.
- Example: "In README.md, Eq.6 missing λT Zi term"

### 2. Ask a Question / Challenge the Theory
- Open Issue > Label: `question`
- Be specific. "What is γ in Eq.14?" is good. "This is fake" is not a contribution.
- Critique welcome. Harassment is not.

### 3. Propose a Protocol Improvement
- Open Issue > Label: `protocol`
- Include: Which protocol (EXP-1 to EXP-4), what to change, why it improves falsifiability, new falsification threshold.
- Do NOT propose removing a falsification threshold. Propose making it stronger.

### 4. Propose a Replication
- Open Issue > Label: `replication`
- Include: Lab / institution, which protocol, resources, timeline, ethics status.
- No replication starts until preregistration agreed.

### 5. Propose Collaboration / Funding
- Email: earthangelventuresph@gmail.com
- Subject: `[COLLABORATION]` or `[FUNDING] EAV-MRCT-001`
- Also open GitHub Issue for public record.

## What We Do NOT Accept
- Edits presenting TMRSCRT as proven when it is not.
- Edits removing falsification thresholds.
- Edits adding claims of inter-layer travel, portals, powers, precognition, healing.
- Edits adding a product, course, or paid service.
- Edits adding an author who did not contribute.
- Edits adding personal data about participants.
- Pull Requests changing v1.0 files without approved Issue first.

## Pull Request Process
1. Open Issue first and wait for approval.
2. Fork repo, create branch: `fix/short-description` or `proposal/short-description`
3. Make change in branch only.
4. Open Pull Request linking to Issue.
5. Wait for review by Angelica Pangan. Only she can merge to main.

## Authorship
Contributions do not automatically equal authorship. Authorship requires substantial intellectual contribution to theory, protocol design, data collection, or analysis, plus agreement to be responsible for work. All contributors acknowledged in CHANGELOG.md. Authors listed with CRediT roles.

## Code of Conduct
By contributing, you agree to follow `CODE_OF_CONDUCT.md`.
