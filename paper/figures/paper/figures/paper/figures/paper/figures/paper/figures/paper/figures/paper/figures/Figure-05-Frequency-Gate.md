# Figure 5 — Frequency Gate
**File:** Figure-05-Frequency-Gate.png
**Title:** 8 Hz vs 12 Hz, 100 ms events
**Project:** EAV-MRCT-001 | TMRSCRT v1.0

## Accurate values — do not change
- Two events: Event 1 at 10 ms, Event 2 at 110 ms. Gap = 100 ms.
- Top row: 8 Hz
    - Ti = 125 ms
    - Both events fall in SAME window → Bound together as one
- Bottom row: 12 Hz
    - Ti = 83.3 ms
    - Events fall in DIFFERENT windows → Resolved as separate
- Each alpha cycle = one sampling window, shown as alternating hatched and blank bands

## Caption
Figure 5. Frequency gate: two events 100 ms apart at low and at high alpha frequency. Each alpha cycle is treated as one sampling window, shown by alternating hatched and blank bands. At 8 Hz the window is 125 ms long, so events at 10 ms and 110 ms fall in the same window and are bound together. At 12 Hz the window is 83.3 ms long, so the same events fall in different windows and are resolved as separate. This is the mechanism behind Postulate 4. The diagram is a model illustration, not a recording.
