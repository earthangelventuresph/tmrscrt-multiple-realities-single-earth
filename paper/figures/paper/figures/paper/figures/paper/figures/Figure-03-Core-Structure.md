# Figure 3 — Core Structure
**File:** Figure-03-Core-Structure.png
**Title:** Ω → Ci → Ri, Dij from Ri only
**Project:** EAV-MRCT-001 | TMRSCRT v1.0

## What it shows — in words, accurate
- Left box: Physical world Ω(x,t)
- Middle: Internal state Ci
- Arrow: Representation map ρi, labelled "lossy"
- Right boxes: Reality states R1, R2, R3...
- Below: Dij computed ONLY from Ri, never from a second world
- No second Earth. No second Ω.

## Caption
Figure 3. Core structure of the theory. The single physical world Ω feeds every observer. Each observer's internal state Ci determines a lossy map ρi, producing the reality state Ri. Reality divergence Dij is computed only from the reality states; it never requires a second physical world. This diagram is the visual form of Postulates 1 and 5.
