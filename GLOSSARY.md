# Glossary — TMRSCRT
**Project:** EAV-MRCT-001

| Term | Definition in TMRSCRT |
| :--- | :--- |
| Ω(x,t) | Physical world state at position x and time t, single, observer-independent |
| Ri(t) | Reality state of observer i: triple (Ii, Ki, Πi) |
| Ii(t) | Information set accessible to observer i |
| Ki | Prior model: learned rules and expectations |
| Πi(t) / pi(e) | Predictive distribution / probability assigned to event e |
| Dij | Reality divergence, Jensen-Shannon, bits, 0-1 |
| Fi / IAF | Individual Alpha Frequency, Hz, peak 7-14 Hz, resting eyes-closed EEG, O1 O2 Oz PO3 PO4 POz |
| Ti | Alpha period, 1000/Fi, ms |
| Bi | Temporal binding window, JND of TOJ, ms |
| t̂i | Estimated present, t + δi |
| δi | Temporal offset, PSS, ms |
| Φi | Represented-future set, pi ≥ 0.50, H = 2 s |
| Λi(e) | Anticipation lead, τe − τ̂e,i, ms, positive = early |
| Zi | Confound vector [Pi, Mi, Ai, Si, Qi, age], k = 6 |
| y | Fractional clock deviation, (ν−ν0)/ν0, dimensionless |
| γ | Physical coupling coefficient, Hz-1, null = 0 |
| PSS / JND | Point of subjective simultaneity / Just noticeable difference |
| Fref | Reference alpha frequency, fixed 10 Hz |
| H | Prediction horizon, fixed 2 s |
| θ | Represented-future threshold, fixed 0.50 |
| ζ0, ζ1, ζ2 | Eq.12 coefficients: residual, per cue, per prior, bits |
| ΔIij / ΔKij | Information difference (cues) / Prior difference (0 same, 1 different) |
| DKL | Kullback-Leibler divergence, base 2, bits |
| ρi | Representation map Ω → Ri, lossy |
| t̂G / wi | Group shared present / Precision weight 1/σi² |

## Pronunciation / Usage
- Say "TMRSCRT" as letters: T-M-R-S-C-R-T
- Say "Jensen-Shannon" as: YEN-sen SHAN-on
- Say "alpha frequency" as: AL-fa FREE-kwen-see
- Do NOT say "vibration" as scientific term. Use Fi.
